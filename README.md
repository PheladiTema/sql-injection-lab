# SQL Injection Lab

## Overview

This project was completed as part of my Zaio Cybersecurity Bootcamp.

The exercise focused on understanding SQL injection vulnerabilities and how
improperly handled user input can affect web applications and databases.

## Objectives

- Understand the fundamentals of SQL injection
- Identify vulnerable application inputs
- Explore how SQL queries can be manipulated
- Understand the security impact of SQL injection
- Consider appropriate mitigation techniques

## Tools & Technologies

- SQL
- Web Application Security
- SQL Injection
- Browser Developer Tools
- Cybersecurity Testing Environment

## Key Learning Outcomes

Through this exercise, I gained practical exposure to identifying and
understanding SQL injection vulnerabilities and the importance of secure
input handling.

## Skills Demonstrated

- Web application security
- Vulnerability identification
- SQL fundamentals
- Security testing
- Analytical problem-solving

This project was completed in an authorised training environment as part
of my cybersecurity studies.
